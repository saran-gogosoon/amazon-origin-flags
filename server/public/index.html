Hosts & blocking defences

  • Detects captcha pages (/errors/validateCaptcha, “Geben Sie die unten angezeigten Zeichen ein”), HTTP 503/429/403, robot and empty pages.
  • Per-host rate limit (amazon.de ≈ 1 request / 8–15 s), exponential backoff with jitter.
  • New session on every block: user agent, matching headers, fresh cookie jar, next proxy from PROXY_URLS.
  • Circuit breaker pauses a host after repeated blocks. A headless browser is the last fallback.
  • Queue lives in SQLite, so a crash or restart loses nothing.
